# Exercícios — Classes e Objetos em Java

## Exercício 1 — Classe Carro

Crie uma classe chamada `Carro`.

A classe deverá possuir os seguintes atributos:

- Marca;
- Modelo;
- Ano.

### Tarefas

- Crie a classe `Carro`;
- Declare os atributos `marca`, `modelo` e `ano`;
- Crie um objeto da classe `Carro`;
- Atribua valores aos atributos;
- Imprima no console os dados do carro.

---

## Exercício 2 — Classe Pessoa

Crie uma classe chamada `Pessoa`.

A classe deverá possuir os seguintes atributos:

- Nome;
- Idade.

### Tarefas

- Crie a classe `Pessoa`;
- Declare os atributos `nome` e `idade`;
- Crie **dois objetos** da classe `Pessoa`;
- Atribua valores diferentes para cada pessoa;
- Imprima no console os dados das duas pessoas.

### Exemplo de saída

```text
Pessoa 1
Nome: João
Idade: 20

Pessoa 2
Nome: Maria
Idade: 25
```

### 🎯 Objetivo

Praticar os conceitos de:

- **Classe**;
- **Objetos**;
