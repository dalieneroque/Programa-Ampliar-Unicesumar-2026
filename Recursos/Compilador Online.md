## 💻 MyCompiler

### Recomendação de compilador Java online

O **MyCompiler** é uma ferramenta online que permite escrever, compilar e executar códigos Java diretamente pelo navegador, sem a necessidade de instalar o Java na máquina.

🔗 **Acessar o MyCompiler:**  
[MyCompiler — Java Online](https://www.mycompiler.io/pt/new/java)
