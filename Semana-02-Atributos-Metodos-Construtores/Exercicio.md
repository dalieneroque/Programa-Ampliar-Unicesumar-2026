# Exercício — Classe Aluno

Desenvolva, em **Java**, uma classe chamada `Aluno`, aplicando os conceitos básicos de **Programação Orientada a Objetos (POO)**.

A classe `Aluno` deverá possuir os seguintes atributos:

- Nome;
- Curso;
- Idade.

### Métodos

Crie um método chamado:

```java
exibirDados()
```

Esse método deverá exibir no console todas as informações do aluno.

### Regras

- Crie a classe `Aluno`;
- Declare os atributos `nome`, `curso` e `idade`;
- Crie um construtor para inicializar os dados do aluno;
- Crie o método `exibirDados()`;
- Crie uma classe principal para executar o programa;
- Na classe principal, crie pelo menos **um objeto** da classe `Aluno`;
- Utilize o método `exibirDados()` para apresentar os dados do aluno.

### Teste obrigatório

O programa deverá apresentar no console informações semelhantes a:

```text
Nome: João
Curso: Engenharia de Software 
Idade: 20
```

### 🚀 Desafio Extra

Crie **dois ou mais objetos** da classe `Aluno`, com informações diferentes, e utilize o método `exibirDados()` para apresentar os dados de cada aluno.

**Objetivo do exercício:** praticar a criação de **classes, atributos, objetos, construtores e métodos** em Java.
