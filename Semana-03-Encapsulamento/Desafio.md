# Desafios

## 🟢 Desafio 1 - Cadastro Aluno

**Crie uma classe Aluno contendo:**

- nome
- idade
- nota

*Todos os atributos devem ser privados.*


**Crie métodos para:**

- definir o nome;
- obter o nome;
- definir a idade;
- obter a idade;
- definir a nota;
- obter a nota.



**Regra**: a nota deve estar entre 0 e 10. Caso contrário, o programa deve apresentar uma mensagem de erro.


**Desafio**:
Impeça que uma idade negativa seja cadastrada

## 🟢Desafio 2 — Funcionário

**Crie uma classe Funcionario com os atributos privados:**

- nome
- salario
- cargo

**Implemente métodos para consultar e alterar os dados.**

**Regras:**

- O salário não pode ser negativo.
- O nome não pode ser vazio.
- O cargo deve possuir pelo menos 3 caracteres.

*Depois, crie três funcionários e apresente seus dados.*

**Desafio:**
Crie um método aumentarSalario(percentual) que permita aumentar o salário sem permitir percentuais negativos.
